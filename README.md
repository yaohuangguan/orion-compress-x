# Orion Compress X (Orion 压缩大师)

Orion Compress X 是一款专业的纯前端媒体处理工具，提供智能图片压缩、多格式图片转换以及视频下载和音频提取功能。

## 功能特性

*   **智能图片压缩 (Compress)**: 
    *   支持批量压缩 JPG, PNG, WebP, BMP, GIF 等格式。
    *   智能算法在保持画质的同时大幅降低文件大小。
    *   可自定义压缩强度。
    *   完全在浏览器本地处理，保护隐私。

*   **万能格式转换 (Convert)**:
    *   支持多种图片格式之间的相互转换（如 PNG 转 WebP, JPG 转 PNG 等）。
    *   支持批量处理。

*   **视频/音频工具 (Video Tools)**:
    *   支持解析 YouTube, Vimeo, TikTok, Instagram 等平台的视频链接。
    *   提供 MP4 视频下载和 MP3 音频提取功能。

*   **国际化支持**:
    *   内置中英文一键切换，默认中文界面。

## 技术栈

*   React 19
*   TypeScript
*   Tailwind CSS
*   Lucide React (图标库)
*   HTML5 Canvas (图片处理核心)

# English Description

Orion Compress X is a professional client-side media processing tool suite featuring smart image compression, format conversion, and media downloading capabilities.

## Features

*   **Smart Compression**: Intelligently reduce file size without visible quality loss. Support for batch processing.
*   **Format Conversion**: Convert between WebP, JPG, PNG, and more instantly in your browser.
*   **Media Downloader**: Download video (MP4) or extract audio (MP3) from major platforms like YouTube and TikTok.
*   **Privacy First**: All image processing happens locally in your browser.
